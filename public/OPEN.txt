Spine Web Viewer  v1.0.6
========================

下载这个压缩包、解压，然后双击启动脚本即可。不要直接双击 index.html。
浏览器不允许用 file:// 打开带模块脚本的页面，启动脚本会在本机临时开一个页面服务并自动打开浏览器。

Windows
  双击 Start-Windows.bat
  若系统里有 Python，会用 Python；没有的话会用系统自带的 PowerShell，不需要再安装别的东西。

macOS
  双击 Start-Mac.command
  若系统提示无法打开，请在文件上右键，选择“打开”。
  需要系统自带的 Python 3。

Linux
  在解压目录执行:
    bash Start-Linux.sh
  或:
    python3 serve.py

浏览器打开后：
  - 开始页只有「打开动画文件夹」。它会扫描整个文件夹，一次加入多套骨架。
  - 加载之后，左侧列表上方的「添加单个」用来再追加一套。
    在同一次文件选择里选中骨架（.json 或 .skel），以及这一套的 .atlas 和贴图。
    页面读不到你没选中的同目录文件，所以只点一个骨架文件不够。
    这一次如果只有一套骨架，图集和贴图的文件名不完全一致也可以配上。
  再次添加会追加到左侧列表，不会清掉已经加载的内容。同一套文件不会重复出现。
  需要重来时，点左侧的「清空列表」。
  预览时默认显示原点坐标轴（红 X、绿 Y）。右侧边栏顶部「原点坐标轴」里的「显示」可以关掉。
关掉启动脚本打开的那个黑色窗口，服务就会停止。

导出 PNG / GIF 需要这个本地页面（浏览器只允许在 localhost 里选择保存目录）。
